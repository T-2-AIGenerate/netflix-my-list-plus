Netflix マイリスト＋（Chrome拡張機能）
=====================================

【インストール方法】
----------------
1. ZIPファイルをダウンロードし、右クリックして「すべて展開」します。
2. Chromeで chrome://extensions/ を開きます。
3. 画面右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開した netflix_my_list_plus フォルダ（manifest.json が入っているフォルダ）を選びます。
6. Netflixのマイリスト https://www.netflix.com/browse/my-list を開き直します。
7. Netflixのマイリスト（https://www.netflix.com/browse/my-list）でのみ右下に表示される「マイリスト＋」を押します。マイリスト以外のページではボタンは表示されません。Netflixのマイリスト関連通信からの自動取得を試みます。取得されない作品がある場合は「マイリスト全体を読み込む」で補完してください。

【使い方】
------
・自動取得：Netflixのマイリストページで、拡張機能がNetflix自身のMy List関連GraphQL通信を監視し、レスポンス内の作品候補を収集します。第三者サービスには送信しません。Netflix側の通信名や形式によっては取得できない場合があります。
・「マイリスト全体を読み込む」：自動取得できない作品がある場合の補助手段です。「マイリスト」列の右矢印を自動で押して、横方向に追加表示される作品を収集します。同じ表示状態を2回検出した場合は先頭へのループと判断して停止します。
・「設定を折りたたむ／設定を展開する」：検索や絞り込みなどの操作欄を収納します。ポスターサイズのスライダーは折りたたみ後も表示されます。
・タイトル表示文字数：タイトルを指定文字数で省略表示します。0を指定すると省略しません。
・収集した作品一覧：Chromeのローカルストレージに保存し、ページを更新しても再表示します。
・検索欄：作品名で絞り込みます。
・表示する作品：すべて／あとで見る／お気に入り／未視聴／視聴中／視聴済みを切り替えます。
・並べ替え：Netflixの表示順／タイトル順／上映時間が短い順／上映時間が長い順／自分の順番を選べます。上映時間が未取得の作品は後ろに表示されます。作品情報が取得されると、上映時間順は自動で更新されます。
・ポスターサイズ：スライダーでカードの大きさを変更します。
・一括操作：カードの「選択」で複数作品を選び、「選択作品の状態」から未視聴／視聴中／視聴済みへの変更、または非表示を選択して「選択作品に適用」を押します。適用前に確認が表示されます。
・タグ追加：作品を選択し、タグ入力欄にタグ名を入れて「タグ追加」を押します。
・視聴状況：作品ごとのメニューから未視聴／視聴中／視聴済みを設定します。
・自作タグ：タグ追加で登録したタグは表示フィルターのプルダウンに表示されます。自作タグを選択した状態で「選択中の自作タグを削除」を押すと、全作品からそのタグを削除します。
・非表示：一括操作の「選択作品の状態」から「非表示にする」を選ぶと、選択作品が通常一覧から隠れます。「非表示」フィルターで確認し、「再表示」で戻せます。Netflix本体のマイリストは変更しません。
・自分の順番：並べ替えを「自分の順番」にして、作品カードをドラッグします。

・拡張機能自身が第三者の解析サービス、広告サービス、外部API、独自サーバーへデータを送信する機能は確認されていません。
・拡張機能の作品情報取得処理は、Netflixのページ（https://www.netflix.com/）に対してリクエストします。Netflix本体は通常のサイト機能として、Netflixが利用する配信基盤などと通信する場合があります。
・作品一覧、タグ、メモ、評価、視聴状況、設定などの拡張機能データは、Chromeの chrome.storage.local に保存されます。これはこの拡張機能用のローカル保存領域であり、Netflixアカウントや他の端末との同期を目的としたものではありません。Chromeのプロファイルや拡張機能の削除・リセットなどによりデータが失われることがあります。
・外部サーバーからJavaScriptなどのプログラムをダウンロードして実行する機能はありません。
・自動取得では、Netflixページ上のMy List関連GraphQL通信を監視します。現行コードは、該当するレスポンスの内容をページ内メッセージ（window.postMessage）でコンテンツスクリプトへ渡し、そこから作品候補を抽出します。この受け渡しはNetflixページ内で行われ、拡張機能が第三者サーバーへ転送する処理ではありません。
・ただし、現行コードはページ内メッセージにレスポンス全体を含めています。作品候補だけに限定して渡す実装ではなく、Netflixページ上で動作する他のスクリプトからそのメッセージを観測される可能性があります。これは第三者へのネットワーク送信を意味しませんが、データ最小化の観点では改善余地があります。本READMEではこの挙動を隠さず記載しています。
・拡張機能はNetflixの非公開・変更される可能性があるページ構造や通信形式に依存します。Netflixの仕様変更によって取得できなくなったり、誤動作したりする場合があります。
・本拡張機能はNetflix公式ではなく、Netflixとの提携・承認を受けたものではありません。

【注意点】
------
・Netflixのサイト構造は変更されることがあるため、作品を検出できない場合があります。
・Netflixの画面構造が変わると「マイリスト」の列や右矢印を特定できない場合があります。読み込み結果のステータスに停止理由が表示されます。
・タイトル名がNetflixのページ上に公開されていない作品は、作品IDのみの表示になる場合があります。
・タグや視聴状況はこの拡張機能内だけの管理情報で、Netflix本体のマイリストを変更するものではありません。
・ドラッグによる並べ替えはこの拡張機能の画面内だけに反映されます。Netflix本体の並び順は変わりません。
・この拡張機能はNetflix公式ではありません。
・この拡張機能は99.9%AI製です。作者はソースコードを殆ど作成していません。

【動作しないとき】
--------------
1. chrome://extensions/ で「Netflix マイリスト Plus」の再読み込みボタンを押します。
2. Netflixのマイリストを再読み込みします。
3. マイリストを下へスクロールしてから「マイリスト＋」を押します。
4. 「作品を検出できませんでした」と表示された場合は、その画面のスクリーンショットを用意してください。Netflixのページ構造に合わせて修正が必要です。

【アンインストール」
----------------
chrome://extensions/ を開き、「Netflix マイリスト Plus」の「削除」を押します。


【v1.7 追加機能】
・ポスター比率を横長（16:9）に変更しました。
・作品カードに上映時間、またはシーズン数／エピソード数を表示します。情報は作品カードが表示範囲に入ったときにNetflixの作品ページから取得を試みます。ページ構造や作品によって取得できない場合があります。
・各作品に「メモを開く／メモを収納する」機能を追加しました。メモはローカルストレージに保存されます。
・作品ごとに0～5の評価を保存できます。星クリック、スライダー、数値入力に対応します。
・設定欄で「5.0段階（0.5刻み）」と「5段階（整数）」を切り替えられます。未評価は0で、星はグレー表示です。
